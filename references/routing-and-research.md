# Routing And Research

## Source Classification

Classify the device as one of:

- Public / standard commercial equipment
- Modified commercial equipment
- Self-built / custom equipment
- Mixed system
- Unknown

When uncertain, protect the user's actual device geometry and treat it conservatively as modified/custom.

## Evidence Priority

Use this order when references conflict:

1. user's real-device photos;
2. user's dimensions, sketches, and notes;
3. exact-model official product imagery/manual/dimensional drawing;
4. exact-model secondary views;
5. same-series equipment;
6. generic web examples.

Internet references are structural evidence, not permission to invent parts.

## When To Search

Search when it materially improves fidelity, for example:

- name/model is known but unseen sides are missing;
- official dimensions can constrain proportions;
- a standard valve/sensor/flange is partially obscured;
- the user asks for research or model verification.

Do not search merely because search is available. For self-built equipment, never replace the custom assembly with a generic online system.

## Soft Gate

Continue if the main device is reasonably identifiable. Warn, rather than reject, when:

- only one useful photo exists;
- there is mild occlusion;
- exact dimensions are absent;
- some small fittings are unclear.

Ask for more material only when high fidelity cannot be achieved without it or the main device is genuinely unidentifiable.
